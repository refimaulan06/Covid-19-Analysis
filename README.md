#Covid 19 Analysis

## Business Problem
The COVID-19 pandemic created major global health and economic challenges. This project analyzes COVID-19 data to identify infection trends, recovery patterns, and mortality distribution across countries in order to support data-driven decision making and public health insights.

## Objectives
- Analyze global COVID-19 case distribution
- Identify countries with the highest confirmed cases and deaths
- Explore recovery and mortality trends
- Discover patterns and correlations within COVID-19 data
- Visualize the impact of the pandemic across regions

## Dataset
Source: Kaggle COVID-19 Dataset

The dataset includes:
- Confirmed cases
- Death cases
- Recovered cases
- Active cases
- Country and regional information

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Tableau

## Methodology
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Data visualization
- Basic clustering and regression analysis

## Key Insights
- COVID-19 cases were heavily concentrated in several high-population countries
- Death and recovery rates varied significantly between regions
- Strong correlations were found between confirmed cases and death counts
- Certain countries experienced rapid spikes in active cases during specific periods
- Data distribution contained significant outliers due to uneven global spread

## Machine Learning (Optional)
- Regression analysis was tested to explore relationships between confirmed cases and deaths
- Clustering analysis identified country groupings based on case distribution and recovery patterns

## Recommendations
- Governments should prioritize healthcare resources in high-risk regions
- Early intervention and monitoring are critical to reducing rapid case growth
- Public health strategies should focus on densely populated areas with high transmission rates
- Further analysis with updated datasets can improve predictive modeling accuracy
